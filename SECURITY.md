# Security Policy 🔒

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of CareerQuest seriously. If you discover a security vulnerability or secret leakage risk:

1. **Do NOT open a public GitHub issue.**
2. Please report the issue privately by emailing `maintainer@careerquest.dev` or using GitHub Security Advisories.
3. Include detailed steps to reproduce the vulnerability, along with any relevant environment details.
4. We aim to acknowledge reports within 48 hours and provide a fix or mitigation promptly.

Thank you for helping keep CareerQuest safe and private for everyone.
